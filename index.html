Projeto 2º Semestre:

No 2º semestre do curso, na disciplina de Interação Humano-Computador (IHC), foi desenvolvido um formulário web de inscrição para um evento de conferência de tecnologia.

O objetivo do projeto foi implementar uma interface com boa qualidade de software e experiência de usuário (UX) – conteúdo teórico da disciplina de IHC. Tecnologias utilizadas: HTML, CSS, JavaScript e Bootstrap.

Projeto 3º Semestre:

O projeto do 3º semestre, realizado na disciplina de estrutura de dados, trata-se de um sistema para gestão de uma livraria desenvolvido na linguagem C. O sistema utiliza as estruturas de dados arquivos e structs.

O sistema consiste em um menu de opções. Basta digitar o número da função desejada e clicar em Enter para executar a função. As principais funcionalidades são: CRUD de livros, autores e clientes. Também funções para venda e funções que relacionam livros e autores.

Projeto 4º Semestre:

Na disciplina de programação web, desenvolvemos uma API Rest voltada à gestão de castração de animais. O intuito do projeto era que ele servisse de apoio as atividades de uma ONG da cidade de Avanhandava.

O projeto foi desenvolvido na linguagem Java com uso dos frameworks Spring e Hibernate. O sistema foi estruturado sob a arquitetura Model-View-Controller (MVC). A API não possui uma interface. Os testes são realizados por meio do Postman, já que as operações de CRUD da API são através de métodos HTTP.

Projeto 5º Semestre:

Como projeto do 5º semestre foi apresentado uma coletânea de comandos SQL de consulta a um banco de dados. Na disciplina de laboratório de banco de dados aprendemos comandos SQL fundamentais utilizando o SGBD da Oracle: SQL Developer.

O banco de dados utilizado para as consultas foi criado em aula. Esse banco registra notas fiscais de compras de produtos. É formado por 5 tabelas: Produtos, Vendedores, Clientes, Notas_fiscais e ItensNotasFiscais.

Projeto 6º Semestre:

Na disciplina de tópicos especiais em informática desenvolvemos, como prova P1, uma aplicação web em PHP que realiza CRUD de produtos e fornecedores e possui funcionalidade de busca e paginação.

Para o front-end da aplicação foi utilizado o framework Bootstrap. Já para o back-end, além do PHP, o banco de dados MySQL gerenciado por meio da ferramenta PhpMyadmin. O projeto foi testado no servidor web local chamado Apache. Para isso, se fez necessário a utilização da IDE Xampp.
